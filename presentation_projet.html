Science des Données

Classification Supervisée : Assurance Automobile

Étudiant : Samuel
Sujet : Prédiction de réclamations (Outcome)
Date : 20 Mai 2026

1. Objectif du Projet

  • Placer les données dans un contexte de classification supervisée.
  • Prédire si un client fera une demande d'indemnisation (Outcome = 1).
  • Identifier les facteurs de risque influençant les réclamations.
  • Fournir un modèle robuste pour la mise en production.

2. Exploration des Données

  • Taille : 10 000 échantillons.
  • Variables : 18 colonnes (17 caractéristiques + 1 cible).
  • Types : Mélange de numériques et catégorielles (Education, Income, etc.).
  • Distribution : 31.3% de réclamations (Outcome=1).

3. Préparation (Data Cleaning)

  • Nettoyage : Suppression des colonnes non-pertinentes (ID, Code Postal).
  • Valeurs manquantes : Imputation par la médiane (Credit Score, Annual Mileage).
  • Valeurs aberrantes : Correction de 5 anomalies majeures dans speeding_violations.
  • Transformation : Encodage (LabelEncoder) et Normalisation (StandardScaler).

4. Facteurs d'Influence

Principales corrélations avec l'Outcome :

  1. Past Accidents : +0.52 (Très significatif)
  2. Speeding Violations : +0.48
  3. DUIs (Conduite sous influence) : +0.42
  4. Annual Mileage : +0.35

5. Comparaison des Modèles

Évaluation par validation croisée (K-Fold=5) :

Modèle Accuracy (Moyenne)
Régression Logistique 84.09%
K-Plus Proches Voisins (KNN) 81.54%
Perceptron 80.01%

6. Résultats : Régression Logistique

  • Accuracy Finale : 83.80% (Test)
  • Précision : 74.30%
  • Rappel (Recall) : 73.83%
  • F1-Score : 74.07%

Le modèle est stable et ne présente pas de surapprentissage (Ecart Test vs CV < 0.3%).

7. Conclusion

  • Objectif atteint avec une excellente précision de 84%.
  • Identification claire des comportements à risque (accidents passés, vitesse).
  • Pipeline de préparation automatisé et robuste.
  • Modèle sauvegardé et prêt pour la production (Pickle).
